# Dragon Language Translator

A Java Swing app that translates between English and the dragon language from Skyrim.

## Features

- Loads English and dragon word pairs from a data file into a `HashMap`
- Looks up the English meaning of a dragon word
- Lets you add new word pairs, which are saved back to the file
- Translates full dragon shouts word by word

## Files

- `DragonTranslator.java`: loads, searches, and saves translations
- `DragonWord.java`, `DragonShout.java`, `StartPage.java`: Swing GUI screens
- `dragonShouts.dat`: word list

## Built with

Java, Swing
